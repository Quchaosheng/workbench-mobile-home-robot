# Release notes

This file is the release record for the multi-scenario work. Outcomes are not
typed here: the phase table below is generated from
[`phase-status-v1.json`](phase-status-v1.json), and a hand-edited table is
refused by `python3 tools/scripts/check_phase_gates.py`.

## How to read this file

- Only the generated block is machine-owned. Edit it by regenerating with
  `python3 tools/scripts/phase_gates.py`, never by hand.
- `COMPLETE` means every declared gate for the phase passes today. It does not
  mean the phase is release eligible, and it does not mean any evidence is
  physical.
- `BLOCKED` means a member Issue is not delivered. The phase names what it is
  waiting on, and the neighbouring phases are unaffected.
- Human sign-off is listed per phase and is never implied by a passing gate.
